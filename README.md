# Student Information Portal

**By:** 2547237, 2547201, 2547259

## About
A web-based student information portal for MCA students at Northstar Academy. Provides a centralized place to view academic journey, schedules, and school updates.

## Features
- 📋 Student overview and profile information
- 🎓 Academic records and progress
- 📅 Course schedule management
- 📢 School notices and announcements
- 📧 Contact information

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Architecture:** Single-page application

## How to Run
1. Clone the repository
2. Open `index.html` in your browser
3. Navigate using the menu to explore different sections
